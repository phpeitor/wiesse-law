## 🚀 Quick Start

1. Clona el repositorio:
```bash
git clone https://github.com/phpeitor/wiesse-law.git
cd wiesse-law
```

2. Ejecuta el proyecto localmente:
```bash
index.html
```

## 📁 Estructura del proyecto

```text
wiesse-law/
├── index.html              # Entrada principal del sitio
├── css/                    # Hojas de estilo y assets del frontend
├── js/                     # Scripts, dependencias y comportamiento
├── img/                    # Imágenes del sitio
├── fonts/                  # Fuentes locales
├── webfonts/               # Fuentes Web adicionales
├── README.md               # Documentación del proyecto
├── .ia-context/            # Guías para agentes y contexto de IA
└── .git/                   # Metadatos del repositorio
```

## 🧩 Descripción

Este repositorio contiene una landing page institucional para un estudio jurídico, desarrollada como una implementación estática y compatible con servidores web tradicionales como Apache. La base del proyecto está diseñada para cargarse desde la raíz del sitio sin depender de un framework ni de un backend.

## 🛠️ Stack y enfoque

- HTML5 semántico
- CSS personalizado y estilos exportados
- JavaScript vanilla y scripts de terceros
- Compatibilidad con Apache/XAMPP
- Arquitectura estática sin build tools ni dependencias de Node

## 🔍 Convenciones del proyecto

- Se prioriza mantener rutas relativas válidas desde la raíz del proyecto.
- Los cambios visuales se realizan dentro de `css/` y los de comportamiento dentro de `js/`.
- El contenido principal vive en `index.html`.
- El directorio `.ia-context/` documenta la estructura y las reglas operativas para agentes y asistentes de IA.

## ✅ Recomendaciones

- Usar Apache/XAMPP o un servidor estático para visualizar el sitio correctamente.
- Revisar los recursos locales antes de agregar assets externos.
- Mantener la navegación y la accesibilidad del sitio durante cualquier ajuste.
- Evitar introducir lógica de backend o frameworks si el proyecto sigue siendo una landing estática.

## 🧠 Nota de mantenimiento

El proyecto está orientado a un desarrollo limpio, mantenible y legible, enfocándose en una entrega eficiente del frontend institucional. La intención es conservar la estructura simple, documentada y fácilmente escalable sin introducir complejidad innecesaria.

*El contexto del proyecto y las reglas de trabajo para agentes están definidos en [.ia-context/AGENTS_ROLES.md](.ia-context/AGENTS_ROLES.md) y [.ia-context/FRONTEND_RULES.md](.ia-context/FRONTEND_RULES.md).*
